# my-portfolio
# 포트폴리오 메인 인덱스 화면 구현 기획서

## 0. 작업 범위
- 목표: 포트폴리오 사이트의 **메인 인덱스 화면 1개**만 구현한다.
- 하위 페이지(메뉴별 상세 페이지)는 이번 범위에서 제외. 링크 대상은 placeholder로 둔다.
- 결과물: 단일 파일 `index.html` (HTML + CSS + JS 인라인).
- 외부 라이브러리는 CDN으로만 로드 (물리엔진: Matter.js 권장 — cdnjs).
- 배포: GitHub 저장소 → GitHub Pages. 빌드 도구 사용하지 않음.
- Supabase: 이번 단계에서는 연결하지 않음. 단, 2단계에서 메뉴 데이터를 Supabase로 옮길 수 있도록 메뉴 데이터를 코드 상단의 설정 객체 하나로 분리해 둔다.

## 1. 화면 구성 개요
- 전체 화면(100vw × 100vh), 스크롤 없음. 화면 자체가 하나의 물리 공간.
- 요소는 3가지:
  1. 배경 (은은하게 움직이는 그라데이션 / 컬러 블롭)
  2. 천장에 매달린 **메뉴 줄 N개** (세로 타이포)
  3. 상단에서 떨어지는 **원형 리퀴드 글래스 구슬 1개**
- 화면 네 변(천장 제외 시 좌/우/바닥 + 천장 포함)에 보이지 않는 벽을 두어 물체가 화면 밖으로 나가지 않게 한다.

## 2. 설정 객체 (코드 최상단에 분리)
```js
const CONFIG = {
  menus: [
    { label: "ABOUT",   href: "#about" },
    { label: "WORK",    href: "#work" },
    { label: "CONTACT", href: "#contact" },
  ],
  rope: {
    segments: 12,          // 줄 마디 수
    segmentLength: 14,     // 마디 길이(px)
    stiffness: 0.9,        // 마디 연결 강성
    damping: 0.05,         // 흔들림 감쇠
    pullThreshold: 160,    // 기본 위치에서 이만큼(px) 아래로 당기면 페이지 열림
  },
  glass: {
    radius: 70,            // 구슬 반지름(px), 모바일에서는 화면 폭 비례로 축소
    restitution: 0.4,      // 바닥 튕김 정도
    density: 0.002,
  },
  gravity: 1,
};
```
- 메뉴명은 이 배열만 수정하면 줄 개수와 글자가 자동 생성되어야 한다.

## 3. 메뉴 줄 + 세로 타이포
- 각 메뉴마다 화면 상단(천장)에 고정점 1개를 둔다. 고정점은 가로로 균등 배치 (메뉴 수에 따라 자동 간격).
- 고정점에서 아래로 줄(rope)이 수직으로 늘어진다.
  - 줄 = Matter.js 원형 소형 바디 여러 개를 `Constraint`로 사슬 연결 (Composites.chain 사용 가능).
  - 줄은 화면에 얇은 선으로 렌더링 (canvas 또는 SVG path, 마디를 부드러운 곡선으로 연결).
- 줄 끝에 메뉴명이 **세로 타이포**로 이어진다.
  - 글자 하나 = 물리 바디 하나. 글자들도 줄처럼 서로 Constraint로 연결되어, 줄과 글자가 하나의 사슬처럼 움직인다.
  - 글자는 위→아래 세로로 쌓인 배열. 각 글자 바디의 위치·회전값을 DOM 요소(또는 canvas 텍스트)에 매 프레임 동기화.
  - 폰트: 굵은 산세리프 1종으로 통일 (Google Fonts 사용 가능). 크기는 화면 높이에 비례.
- 인터랙션:
  - 글자 아무거나 마우스/터치로 잡고 드래그 → 줄 전체가 당겨지며 자연스럽게 늘어지고 흔들림.
  - 놓으면 진자처럼 흔들리다 감쇠되어 원위치로 돌아옴.
  - **당김 판정**: 드래그 중 해당 메뉴 사슬의 마지막 글자가 기본 위치 대비 `pullThreshold` 이상 아래로 내려간 상태에서 손을 놓으면 → 해당 메뉴의 페이지 열림.
    - 열림 연출: 줄이 '툭' 끊기는 효과(고정점 Constraint 제거 → 글자들이 바닥으로 떨어짐) 후 화면 전환.
    - 하위 페이지는 미구현이므로 지금은 `href`로 이동하거나, 화면 전체에 페이드 오버레이 + "준비 중: {label}" 표시 후 닫기 버튼으로 복귀 (복귀 시 줄 재생성).
  - 임계값 근처에서는 줄 색이나 글자 투명도를 살짝 바꿔 "더 당기면 열린다"는 피드백 제공.

## 4. 리퀴드 글래스 구슬
- 페이지 로드 직후 화면 상단 밖(또는 상단 근처)에서 생성되어 중력으로 **바닥까지 떨어짐**, 약하게 튕기고 멈춤.
- 물리: Matter.js 원형 바디. 바닥/좌우 벽과 충돌.
- 드래그: 구슬을 **클릭(터치) 후 홀드한 상태로 드래그**하면 화면 내 자유 이동.
  - 위치를 직접 덮어쓰지 말고 `MouseConstraint`(스프링 방식)로 끌어서, 이동 중에도 충돌 판정이 유지되게 할 것.
  - 놓으면 그 순간의 속도로 던져지고 다시 중력 적용.
  - 터널링(빠르게 움직일 때 줄을 통과하는 현상) 방지: 엔진 업데이트를 프레임당 여러 번 서브스텝으로 나누고, 구슬 최대 속도를 제한.
- 충돌 규칙:
  - 구슬이 줄·글자 바디와 부딪히면 → 줄이 밀려나며 흔들리는 물리 반응.
  - 구슬은 줄/글자 안으로 **절대 파고들지 않음**. 줄 위에 놓거나 걸치면 줄이 구슬 모양대로 휘어지며 구슬이 줄 **바깥에 걸쳐진** 상태로 유지되어야 함 (구슬이 줄에 얹혀 매달려 있을 수 있음).
  - 이를 위해 줄 마디 바디 간격을 촘촘하게(마디 반지름 ≥ 간격의 절반) 설정해 틈이 생기지 않게 한다.
  - 구슬과 줄 마디끼리는 충돌, 같은 줄의 마디끼리는 충돌하지 않도록 collisionFilter 그룹 설정.
- 드래그 우선순위: 포인터 아래에 구슬과 글자가 겹치면 구슬을 우선 잡는다.

## 5. 리퀴드 글래스 렌더링
- 구슬은 물리 바디 위치에 동기화되는 원형 DOM 요소로 렌더링.
- 스타일 구성:
  - `backdrop-filter: blur(...) saturate(...)` 로 뒤 배경/글자가 비치며 흐려짐.
  - 반투명 흰색 배경 + 얇은 밝은 테두리.
  - inset box-shadow로 상단 가장자리 하이라이트, 하단은 은은한 반사광.
  - 가장자리 굴절: SVG `feTurbulence`/`feDisplacementMap` 필터를 backdrop에 적용해 뒤 배경이 가장자리에서 휘어 보이게. 지원하지 않는 브라우저(Safari, Firefox)에서는 일반 블러로 자연스럽게 대체되도록 기능 감지 후 분기.
  - 구슬 이동 속도에 따라 하이라이트 위치가 이동 방향 반대쪽으로 살짝 밀리는 효과 (선택).
  - 드래그 중에는 구슬이 살짝 커지거나 눌린 듯 변형(scale) — 물방울 같은 말랑함.
- 구슬이 글자 위로 지나가면 글자가 굴절·흐림 처리되어 보여야 함 (글자가 구슬 뒤 레이어에 있어야 backdrop-filter가 적용됨 → z-index: 배경 < 줄/글자 < 구슬).

## 6. 반응형 / 접근성 / 성능
- 리사이즈 시 벽 위치, 줄 고정점, 구슬 크기 재계산 (디바운스).
- 모바일 터치 드래그 지원, 드래그 중 페이지 스크롤/새로고침 제스처 방지 (`touch-action: none`).
- `prefers-reduced-motion` 사용자는 물리 대신 정적인 세로 메뉴 + 정지된 구슬 표시.
- 키보드/스크린리더용으로 시각적으로 숨긴 `<nav>` 링크 목록을 별도로 제공.
- 탭이 비활성일 때 엔진 정지. 60fps 목표, 렌더링은 requestAnimationFrame 1개 루프에서 처리.

## 7. 완료 기준 (체크리스트)
- [ ] CONFIG.menus 배열 수정만으로 줄·글자 수가 바뀐다.
- [ ] 줄에 매달린 세로 글자를 드래그하면 줄 전체가 자연스럽게 흔들리고, 놓으면 감쇠되어 멈춘다.
- [ ] 임계값 이상 당긴 뒤 놓으면 줄이 끊기는 연출 후 해당 메뉴 페이지(placeholder)가 열린다.
- [ ] 로드 시 구슬이 위에서 떨어져 바닥에 안착한다.
- [ ] 구슬을 홀드-드래그로 자유롭게 옮기고 던질 수 있다.
- [ ] 구슬이 줄/글자와 부딪히면 줄이 흔들린다.
- [ ] 구슬은 줄을 통과하지 않고, 줄 위에 걸쳐질 수 있다.
- [ ] 구슬 뒤로 지나가는 배경과 글자가 유리처럼 흐리고 굴절되어 보인다.
- [ ] 모바일 크롬/사파리에서 터치로 동일하게 동작한다.
- [ ] 단일 index.html로 GitHub Pages에 올렸을 때 그대로 동작한다.

## 8. 작업 순서 제안
1. 빈 물리 월드 + 벽 + 구슬 낙하/드래그
2. 메뉴 줄 1개 + 세로 글자 + 드래그
3. 구슬 ↔ 줄 충돌 튜닝 (통과 방지, 걸쳐짐)
4. 당김 임계값 → 끊김 → placeholder 페이지
5. 리퀴드 글래스 스타일링 + 배경
6. 반응형·접근성·성능 마무리
각 단계마다 브라우저에서 확인 가능한 상태로 커밋할 것.
