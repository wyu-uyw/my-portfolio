내 작업물을 쌓아가는 개인 포트폴리오

작업물을 계속 업로드하며 쌓아가는 개인 포트폴리오 웹사이트. 첫 번째 프로젝트인 졸업 전시 출품작 소개부터 시작한다.

초안입니다. 미정 표시가 붙은 항목은 아직 정하지 않은 것이고, 확정되면 표시를 지웁니다.
화면 UI/UX와 구현 지침(인터랙션, 컬러, 폰트, 배경 패턴 등)은 저장소의 README.md에 정리되어 있습니다.

01. 기획 배경

졸업 전시에서는 작품만 놓여 있어서, 무엇을 왜 만들었고 어떤 과정을 거쳤는지까지 전하기 어렵다. 그 맥락을 웹에서 보충하고, 결과물보다 문제를 바라보고 풀어가는 '작업자'로서의 나를 보여주고 싶다. 졸업 전시를 첫 프로젝트로 시작하지만, 궁극적으로는 새 작업이 생길 때마다 업로드해 작업 이력이 쌓이는 개인 포트폴리오로 계속 쓰려고 한다. 사이트 자체도 줄을 당겨 메뉴를 여는 물리 인터랙션으로 만들어, 첫 화면에서부터 구현 역량이 드러나게 한다.

01-1. 리서치 — 아티스트 포트폴리오는 어떻게 생겼나

일반적인 아티스트 포트폴리오 구성과 텍스타일 작가 사례를 찾아본 결과, 업계에는 갤러리 웹사이트와 비슷한 표준 구조가 뚜렷했다. 이 구조를 따르면 갤러리 디렉터·컬렉터가 "전문적으로 활동하는 작가"로 읽는다. 하위 페이지 사이트 지도 v2는 이 리서치를 근거로 만들었다.

업계 기본 틀

  • 필수 3페이지 — Works(작품 선별), About(Bio · Statement · CV), Contact. Contact는 About과 합치기도 한다.
  • 선택 페이지 — 뉴스·이벤트(예정 전시, 수업 등 작가를 만날 기회), 블로그(검색 노출, 작업을 둘러싼 이야기), 상점.
  • Works — 시간순·매체별·내용별 중 작가에 맞게. 시리즈로 작업하면 시리즈 단위로 나눈다. 너무 많은 작품으로 압도하지 않는다.
  • About — Bio · Statement(작가 노트) · CV. CV에는 교육, 전시, 수상·지원금, 언론, 소장처. 최신순, PDF 제공, 웹 CV에는 전화번호를 뺀다.
  • Contact — 별도 페이지와 별개로 모든 페이지 하단에 SNS와 함께 은은하게.

텍스타일 분야에서 눈에 띈 점

  • 직물을 직접 다루는 손 작업 사진이 공예 역량을 증명한다.
  • 신진 작가는 잘 기록된 졸업 작품 하나로도 초기 포트폴리오를 충분히 이끈다.
  • 자수나 패브릭 매니퓰레이션을 명시하면 차별점이 된다.
  • 프린트·패턴은 도용 위험이 있어 미공개 작업 보호 영역을 권한다.
  • 꾸준한 업데이트 — 2년간 변화 없는 사이트는 활동이 없는 것처럼 읽힌다.
  • 웹사이트는 작품의 받침대 — 형식이 작품을 방해해선 안 된다.

전시 관람객전시장에서 휴대폰으로 접속. 이 작품이 무엇인지 한 줄 소개와 핵심 이미지·영상으로 빠르게.

졸업 전시 시기에는 관람객, 졸업 이후에는 채용 담당자가 가장 우선하는 독자다.

03. 디자인 방향

  • 사이트명 — 임시로 PORTFOLIO 미정
  • 메인 컬러 — 3가지
    배경 블루 #0356fc 화이트 #ffffff 포인트 옐로 #fcad03
    파란 바탕에 흰 글자, 줄을 끝까지 당겼을 때만 노란색으로 바뀌는 피드백. 폰트는 Pretendard.
  • 배색 전환 — 버튼 하나로 블루와 화이트의 자리를 바꿔 볼 수 있다.
    기본 · 파란 배경 + 흰 글자 반전 · 흰 배경 + 파란 글자
    메인은 우측 상단, 하위 페이지는 푸터에 버튼이 있고, 고른 배색은 브라우저에 기억되어 모든 페이지에 이어진다. 포인트 옐로는 두 배색 모두 그대로 쓰고, 반전 배색에서는 메인 이름 외곽선만 흰색으로 바꾼다.
  • 메뉴 구성 — WORK(컬렉션·스와치) / JOURNAL(작업 일지) / ABOUT(Bio·Statement·CV) / CONTACT(연락하기). 천장에 매달린 줄 끝의 세로 글자로 표시하고, 줄을 당겼다 놓으면 열린다.
  • 회전 레버 → 사이트맵 — 메인 왼쪽 세로 중앙에 흰 직선 하나로 된 레버. 돌리면 화면이 레버 끝을 축으로 함께 돌면서 뒷면의 사이트맵이 올라온다. 상단의 PORTFOLIO 글자와 White/Blue · plan-draft 버튼은 제자리에 남는다.
  • 참고 사이트 — Day4에서 고른 스타일 미정

04. 핵심 기능

꼭 필요한 것

  1. 줄 당기기 메뉴 + 유리구슬 메인 화면 — 줄을 당겨 메뉴를 열고, 유리구슬을 잡아 던질 수 있는 물리 인터랙션. 모바일 터치에서도 동일하게 동작. 왼쪽 레버를 돌리면 화면이 회전하며 사이트맵으로 바뀐다.
  2. 작업물 목록과 상세 — 프로젝트를 카드로 모아 보고, 각 프로젝트는 개요 → 배경 → 과정 → 결과물 → 회고의 같은 틀로 읽는다.
  3. 소개와 연락처 — 이름·전공·작업 방식·기술 스택, 이메일과 GitHub·인스타그램 링크.

나중에 되면 좋은 것

  1. 작업물 업로드 — 코드를 고치지 않고 Supabase에 프로젝트 데이터만 추가하면 사이트에 올라가게.
  2. 작업물 거르기 — 작업이 쌓이면 연도·분야별 필터, 습작용 짧은 카드.

06. 얻고 싶은 것

졸업 전시를 계기로, 졸업 뒤에도 작업을 올릴 때마다 자라나는 나만의 포트폴리오를 갖고 싶다. 링크 하나로 내가 어떤 작업자인지 보여주고, 사이트 자체로 인터랙션을 직접 만드는 역량까지 증명하고 싶다.

부록 · 아직 정할 것

  • 실제 이름·연락처 (현재 메인 화면의 "KIM HANEUL" 등은 임시 가명)
  • 졸업 전시 프로젝트명과 한 줄 소개, 개인/팀 작업 여부와 역할 분담
  • 전시명·기간·장소, 전시 부스 QR 코드 연계 여부
  • 도메인 (GitHub Pages 기본 주소를 그대로 쓸지)
  • 졸업 전시 이후 첫 화면 문구·프로필을 어떻게 바꿀지
